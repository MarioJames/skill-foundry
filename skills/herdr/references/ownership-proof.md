# Ownership proof

Read this when `name-tab.ts` or `resolve-caller.ts` fails and you need to know why. Ownership of a tab is proven, never assumed:

1. **Process ancestry** (`tab.proof: "process-ancestry"`), always tried first. A foreground PID of the candidate pane from `pane current --current` must be this invocation or one of its OS ancestors; the invocation itself counts, for a command run directly in the pane's shell. This covers Claude Code, a Codex TUI with its in-process app-server (even while an unrelated shared daemon runs on the host) and other direct terminal hosts. A proven process can label its own tab even when the terminal shows an independent activity title.
2. **Native-title challenge** (`tab.proof: "native-title-challenge"`), only when process ancestry fails for a `CODEX_THREAD_ID` and a shared local app-server is running: a thread served by that daemon runs its tools outside the TUI's process tree. The thread must already carry its formal native name. The script temporarily sets this exact thread's native name to an unpredictable one-use marker, requires exactly one live Codex client to echo it in its terminal title through `herdr agent list`, lets client updates settle, then binds that pane. It restores the formal name in `finally`, restoring only its own marker and preserving a concurrent edit (reported as a conflict). A brief temporary title is visible only on this path. No echo or multiple matching panes fails safely without changing any tab.

For either proof, pane/tab/workspace/terminal IDs and the live proof are rechecked immediately before the write. A lost proof, identity conflict or uncertain write stops the operation: it never falls back to another target, and a timed-out write is not permission to replay it. On failure, skip labelling and continue the task; do not turn a candidate ID into `--caller-pane`, retry with environment IDs removed, search by title/cwd, or substitute a focused pane.

Raw `herdr pane current --current` is only a candidate lookup: it can return an inherited stale pane ID or fall back to focus. Matching `HERDR_*`, `CODEX_THREAD_ID`, Agent kind or cwd alone does not prove ownership, since a long-lived host can inherit all of them from another Agent. The installed Herdr Codex SessionStart hook may also report every thread to a daemon-inherited `HERDR_PANE_ID`, so an `agent_session` match is not evidence either. `CODEX_SESSION_ID` can identify a parent session tree and is not a substitute for the current thread. Do not cache the binding across resumes, client switches or later tasks.

The script never starts or restarts the Codex daemon, resumes threads, or changes focus, workspace names, order or panes. The tab label, the terminal activity title (`terminal_title`) and the conversation title are separate values. `scripts/resolve-caller.ts` returns the verified caller (process ancestry only) without writing anything.
