# 后端实现习惯

按本次涉及的小节读取，结合实际组件、接口和项目约定使用。

## 职责与接口

- 部署链接使用当前环境的有效基址，不混用其他环境或站点的地址。
- 配置修改在实际消费端生效，不以管理接口保存成功代替集成完成。
- 拆包同步迁移公开入口及全部消费者，不留下双份实现、旧入口或重复实例。
- API 按职责组织并在实际入口挂载，接口由拥有相应数据的模块负责。
- 字段存储形式依据实际查询和扩展需求选择，未消费的模型和字段不提前预建。
- 子包沿用项目已有的环境配置来源，构建期开关和运行时变量分别生效。
- 容器代理在上游滚动更新后仍能解析新地址并正常请求。
- 适配层转换供应商真实输出，抽象后保留原消费者行为，不要求供应商配合自创 DTO。
- 移除外部集成保留自身数据库和已有能力，不顺便预建下一套集成架构。
- 共享模块不把仅服务端可用的依赖带入浏览器入口。
- 部署配置说明变量用途和必填性，构建期开关不冒充运行时配置，有状态依赖固定受支持版本。
- 租户数据连接、权限和对象前缀使用可信租户范围，跨库关联符合隔离方式，动态连接池能够释放。
- 目录和共享模块沿用项目最终结构，alias 在运行、测试及构建中都能解析，迁移后清理未使用依赖。
- 部署配置与实际框架和目标项目一致，构建命令、产物及依赖导出同步更新。
- 同义环境变量确认语义一致后统一，删除旧配置同时清理消费者和部署说明。

## 数据与迁移

- 跨类型关联使用能唯一确定对象的键，不因不同类型共享同一 ID 而关联错误。
- 数据库升级基于真实迁移记录和历史数据验证，不用空库成功或清库替代升级验证。
- 只有允许缓存的读取或验证才复用缓存，数据、权限变化和过期按约定失效。
- 日期范围按项目约定的时区和边界换算，保存、查询与回显使用相同口径。
- 写入成功后再失效缓存并重取列表，变更同步到实际消费端。
- 关联使用稳定标识，不因显示名修改而丢失或错配历史数据。
- 删除关联对象的处理方式前后端一致，批量删除不留下悬空关联。
- 已部署迁移前缀不重写，未交付迁移按最终功能整理，不为开发库中间状态增加客户兼容层。
- 写入只修改本次意图涉及的字段，省略、null、零值和默认值区分处理，失败回滚且不覆盖并发更新。
- 先修改 schema/model，再使用项目迁移工具生成产物，不手改生成的 SQL、snapshot 或 journal。
- 开发数据库和迁移记录默认保留，不为测试通过或整理迁移清空已有数据。
- 允许复用的外部标识重新创建后，不仅凭相同标识接管旧对象的身份关联。

## 授权与诊断

- 隐藏或禁用入口不替代接口授权检查，页面跳转、直达和接口调用采用一致的权限判定。
- 权限变化及时失效相关缓存，服务端独立校验授权，不信任前端缓存的权限结果。
- 要求二次验证的写入只有在验证成功后才执行，验证失败或取消不触发保存。
- 注册和账号恢复的输入反馈不泄露账号是否存在。
- 供外部客户端调用的接口在服务端校验凭据并传递身份上下文，不依赖管理页面的浏览器登录态。
- 一次性换票凭证首次成功后失效，不把这一生命周期套给持久登录会话。
- 敏感操作分别识别操作者与目标账号，不混用两者的验证凭据和会话。
- 要求即时撤权时验证既有会话、下载链接和直接接口的实际拒绝结果，不以阻止新登录代替存量访问撤销。
- 诊断日志的降噪和过滤不吞掉实际需要排查的失败事件。
- 日志结果对应操作真实结果，业务拒绝与记录缺失分别表达。
- 异步链路结束后状态同步为真实结果，不永久停在已开始。
- 日志保留开始、结束、错误和关键流转，按实际吞吐控制单请求数量，不重复存储已有平台可查询的完整正文。
