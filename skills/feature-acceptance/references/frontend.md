# 前端实现习惯

按本次涉及的小节读取，结合实际组件、接口和项目约定使用。

## 表单与输入

- 页面、新建和编辑弹窗的自由输入字段都有填写提示，包括技术字段；固定选项、开关和上传按钮不套输入提示规范。
- placeholder 提供示例值或具体填写指引，不重复字段名或“请输入＋字段名”。
- URL 示例使用符合字段协议的完整地址，标识给出示例值，金额标明单位，密钥提示粘贴操作，示例不包含真实凭据。
- 国际化表单的 placeholder 使用现有语义 key，并提供对应语言的真实翻译。
- 默认值清空后仍有有效 placeholder，tooltip 和辅助说明不能替代输入提示。
- placeholder 使用普通字重，不继承 label 的加粗样式。
- 表单采用清晰的上下布局，解释性说明放对应字段的 tooltip，输入示例仍留在 placeholder。
- 成对的范围输入与各自的边界选项相邻分组，联动后不保留与当前范围矛盾的值。
- 使用表单组件显示必填状态，不给每个非必填字段重复标注“可选”。
- 范围输入用明确文案说明不限、单侧限制和边界含义，不向用户暴露内部区间表达式。
- 身份验证中的方式选择、密码确认等重复表单复用已有组件，标签、布局、tooltip 和允许的输入方式保持一致。
- 组合字段的外层用不带 name、只设置 required 的 Form.Item 提供必填标记和间距，不重复绑定字段或手工叠加 margin。
- 逐项密码规则实时显示达标状态，全部通过才允许提交，确认密码只校验一致性，不再重复显示总体强弱提示。
- 带说明的 Segmented 复用同一封装，切换选项同步说明，选项宽度随文字、说明占满容器并自动换行。
- 控件类型符合单选或多选语义，编辑值与接口格式双向转换，压缩布局不改变选择能力。
- 长表单按信息用途分组，条件字段随当前选项显示，打开帮助不丢失未提交内容。
- 行内编辑的保存和取消紧邻输入框，Enter 只保存一次，取消不写入，字段校验在前后端一致。
- 需要显式保存的设置在切换选项时只更新草稿和说明，点击保存后才改变实际策略。
- 系统生成的内部标识不要求用户手填，外部接入所需的配置保留真实输入。
- 提交失败结束 loading、保留弹窗和输入并允许重试，提交中防止重复操作，切换编辑记录时不残留上一条数据。
- Modal 表单优先复用 destroyOnHidden 和展示后回填能力，不为同一生命周期额外维护 pendingFormValues 或重复 resetFields。

## 详情与展示

- 只读键值信息复用已有 Descriptions，不伪装成可编辑表单。
- Descriptions 的 label 宽度以不换行为准，主要空间留给内容。
- 不同类型的信息用小标题分组，不为每个字段套卡片。
- 只有内容一个字段且适合代码块时直接展示代码块，不增加无信息量的 label。
- 排障标识并入所属元数据区域，不重复拆成独立模块。
- 标题、Descriptions 和后续表格之间保留清晰间距。
- Descriptions 优先紧凑尺寸，短字段可同排、长内容留足宽度，列数服从内容和当前布局，不强套其他页面的单列或双列设置。
- 采用 ProDescriptions columns 时统一声明描述项并选择对应 valueType，边框与页面约定一致。
- 要求独占一行的长字段实际占满一行，代码块有清楚的标题和归属。
- 允许行内编辑的描述项复用已有编辑组件，不可编辑的原因紧邻对应字段。
- 列表迁移保留查询、重置、刷新和已有操作，列表级操作放在表格操作区并清理残留局部样式。
- 同类复制入口保持图标和文案一致，隐藏正文不删除原本已允许的复制能力，视觉换行或间距不改变复制值。
- 自然撑高的详情表格不再内滚，sticky 表头贴顶且不露出穿透行，圆角在深浅主题下完整。
- 导出当前查询结果时使用最后一次成功生效的查询条件，不采用未提交或查询失败的草稿，实际文件格式与说明一致。
- 面向用户的操作和对象显示可读名称及翻译，不用内部枚举代替业务文案。
- 只读状态使用 Tag/Badge，允许直接编辑的状态才使用 Switch，操作入口与状态语义一致。
- Select 使用已有 loading 状态，不重复增加加载文本，搜索防抖和选项回填正常生效。
- 无数据时使用真实空态或隐藏模块，不保留假的评分、评论、数量或无意义占位。
- 图片 URL 和内置图标使用对应渲染组件并保持视觉尺寸一致，上传结果正确回填，危险操作复用组件 danger 样式。
- 页面壳和内部组件不重复展示标题，主副标题的顺序、对齐和间距一致。
- 操作覆盖完整的预期点击区域，需复制的内容可选择，快捷键可辨识，已有设置弹窗不再重复配置入口。
- 短值列收窄、长值列留足空间，长路径不撑出异常行高，关联对象显示可读名称。
- 独立筛选条件不与泛化搜索重复，时间范围作为一个条件，查询项顺序和跨度符合页面布局。
- 可调整表格的宽度由 column 控制，内部渲染占满可用列宽，不额外用 max-width 缩窄内容。
- 项目支持的非拉丁显示名在输入、查询、展示和实际消费端完整保留，不被无依据的字符过滤拒绝。
- 普通业务 ID 不被凭据脱敏器误替换，修复误判时保留真正敏感字段的脱敏。
- 有图片时显示真实图片，缺失或失败时再回退，列表与详情切换不破图、反复闪烁或丢失已有图片。
- 筛选、分页和刷新保留符合当前操作语义的选择状态，不把展示全部解释为授予全部。
- Client Secret 等普通详情值使用 Descriptions.Item，Alert 留给风险或状态说明，不充当普通内容容器。

## 交互与状态

- 公共主题与组件配置由现有入口统一管理，不在业务组件内重复包相同 Provider。
- 公共主题重构保持原有页面效果，受影响组件的前后证据使用相同页面状态。
- 主题控件消费已有 token，背景与文字、选中态与对勾在深浅主题下均可辨识。
- 刷新和慢网络加载期间不短暂丢失样式，SSR 页面不产生水合错误。
- 主题首次切换立即生效，弹出层、表格和操作按钮同步更新，不靠刷新或更改按钮语义修颜色。
- 同次失败只反馈一次，合并错误仍能展开可定位的详情，文案说明真实原因和影响。
- 自动关闭通知在悬停时暂停，身份验证失败明确区分密码错误与系统加载故障。
- Alert 用于静态说明、风险警告或持久业务状态，不重复显示共享通知已处理的请求错误；字段错误留在表单项。
- 用户文案解释操作用途，不暴露内部实现术语，变更预览保留具体增删内容。
- 局部邮件修改保持原有模板，验证码与登录邮件风格一致，正文不被误折叠为引用。
- 页面切换保留共享 layout，加载、主题和基础组件复用项目已有能力。
- 弹窗和抽屉内容超高时在正确容器内滚动，主要内容和底部操作保持可达。
- 页面内容使用可用空间，不因重复卡片、padding 或固定尺寸挤压内容。
- 主题、语言、长文案和 RTL 在项目支持范围内可用，不擅自增加已明确排除的移动端布局。
- 依赖用户或权限的页面等初始化完成再判断状态，不因尚未加载完成而误报无权限或闪回登录页。
- 一次失败产生的临时错误状态和 URL 参数在消费后清除，不污染下一次操作。
