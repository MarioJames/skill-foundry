# 规则索引

规则按工程选择、前端实现、后端实现和项目范式分为四类。开始实现时读取相关约束，交付前复核，不要求一次读完所有规则。

| 类别 | 读取范围 |
| --- | --- |
| 工程选择原则 | [方案、复用、封装与复杂度](preferences.md) |
| 页面、列表、表单、抽屉和异步流程 | 先读 [交互与状态](frontend.md#交互与状态)，按涉及内容补读 [表单与输入](frontend.md#表单与输入)、[详情与展示](frontend.md#详情与展示)；视觉规则按 `lobe-design` 路由读取 |
| 后端实现习惯 | [职责与接口](backend.md#职责与接口)、[数据与迁移](backend.md#数据与迁移)、[授权与诊断](backend.md#授权与诊断) |
| 项目范式补充 | 采用 Lobe/Admin 范式时读取 [具体写法](lobe.md) |
| 运行时缺陷、库行为矛盾、重复纠偏和依赖约束 | [反馈沉淀与归属](evolution.md) |

保留能帮助 Agent 在相似任务中提前作出符合用户习惯的选择的规则；个人偏好不要求跨项目普适，具体业务结果以当前需求为准。确定性检查由脚本或项目原生工具执行，这里只保存需要理解实现与运行状态的约束。
