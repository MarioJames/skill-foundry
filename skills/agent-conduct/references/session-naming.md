# 会话命名细则

输出里有 `skipped` 或 `failed`、要交接命名归属、或话题由任务调度派发时读本文。

- **`skipped` 和 `failed` 不强行处理。** 脚本只改能证明属于本次运行的标题：LobeHub 话题、Codex 线程，以及经 herdr 命名的标签页；Claude Code 没有可写的标题接口。继承了父会话的环境、群组共享话题、运行已结束时记为 `skipped`。写入超时或读回不一致时不重放，读一次现状后报告。任务照常继续。
- **直接设置，不征求确认。** 不管现有标题是谁设的；只改标题，不动项目、分组、顺序、置顶和归档。
- **任务调度派发的话题照常命名。** 主题写这次任务的具体目标，可以带任务编号，如 `1115｜FIX｜T-123 图片上传失败`；不照抄派发提示词，不改任务本身。
- **命名归会话的所有者。** 归属看交接内容。子 Agent、fork、worker 有自己独立的话题、线程或标签页时命名自己的，不改父会话的。新建标签页的一方负责初始命名（herdr 的 `route-lane.ts --label`），交接里写明 caller、目标 ID 和命名归属。
