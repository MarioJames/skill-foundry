# 本地协作配置页

使用 Bun 1.4.2。在此目录执行 `bun install`，再运行：

```bash
bun ../scripts/agents-config.ts web --config /absolute/path/config.json --state /absolute/path/state.sqlite
```

`--port N` 指定本机端口，`--no-open` 关闭自动打开浏览器。省略路径时沿用 CLI 的配置和状态环境变量。页面仅供本机使用，保存目标由启动时固定，浏览器不能更改文件路径。Ctrl-C 停止服务。普通 CLI 无需安装 Web 依赖。

默认打开浏览器时，命令返回成功只表示系统打开命令已完成，不保证窗口已经显示；失败会提示实际服务 URL。超过五秒尚未确认结果时同样显示 URL，服务继续运行。打开命令独立于服务的前台进程组，超时、Ctrl-C 或 SIGTERM 均不会主动终止已启动的打开命令或浏览器，服务退出也不等待浏览器结束。

可视界面编辑引擎、负责人、工作代理、引用、启用状态、模型、effort、标签、并行上限、Owner Agent 单次等待上限和 ChatGPT Pro 自动审查开关。负责人工作代理按显示顺序参与派发，拖动手柄调整顺序，也可使用上移或下移按钮。配置 ID 使用普通输入框，失焦或按 Enter 接受有效修改，保存和校验也会先接受当前输入；空值、格式错误和重复 ID 在字段内提示并阻止提交。输入按实体保留，切换实体或分区不会丢失，也参与未保存提示、刷新保护、重新加载与放弃确认。引擎重命名同步负责人和工作代理的 engine 引用；工作代理重命名同步负责人列表，保持顺序。未知字段不递归替换。删除仍保留其他对象的引用，交由完整校验指出错误。

表单保留未知字段，由后端复用现有 schema、引擎规则及枚举校验。模型可自由输入；有固定 effort 集合的引擎从单一元数据生成下拉选项，opencode 的 provider/model variant 仍可自由输入。标签支持自由输入与 Enter 添加。

字段类型无效时，控件显示安全的空值或可展示部分；切换表单或修改其他字段均保留原始错误值和未知字段，完整草稿校验仍报告原路径错误。

引擎表单的额度恢复时间以本机 `Intl` 时区显示同一时刻，保存发送含 `Z` 的 ISO 时间。仅编辑精确引擎级限制，模型级限制保持原样；启用开关独立。未改动的空日期不解除无日期限制；明确清空已有或已编辑日期才提交解除。新时间必须有效且晚于当前时间；已有过期日期只提示已到恢复时间，不自动写入。额度读取失败在日期区域显示真实错误和重试，普通配置仍可编辑。

任务看板通过 `GET /api/agents` 只读展示已登记的协作 Herdr 任务，分成进行中、已完成、已关闭三列，列头有数量。点击任务卡打开详情，主区按时间显示调度时间线；详情单独请求，看板列表不带事件。之后的 run/lane 变化会自动留下调度事件。启用记录前的旧任务只保留已知历史概要，不补造中间过程。读取使用启动时指定的状态库，不创建、不迁移、不写入。只覆盖 Herdr 登记；未登记的 native 会话和独立 CLI 不会自动关联进来。

配置及日期共用顶部“保存配置”、未保存提示、离开保护与放弃/重载确认。保存前先校验日期；有配置改动时先保存配置并接收新 revision，再保存显式修改的日期。配置失败不写日期；配置成功而日期失败时明确提示部分成功，保留日期输入，重试只提交未完成或后来新增的改动。两类保存中都可继续输入，响应只清理提交后未改变的项目，不覆盖新输入；两次写入不构成跨文件事务。引擎改名仅重映射尚未保存的日期草稿，不迁移已有运行历史，删除引擎也不清理历史限制。

“校验草稿”使用未保存配置，报告完整草稿中的字段和引用错误。重新加载、保存、校验、放弃修改及状态反馈集中在页头操作区；未保存状态也集中在页头。页面不展示配置来源或保存路径；路径由启动参数固定，内部快照与冲突保护照常工作。“系统设置”中的“Owner Agent 等待上限”控制 Owner 每次通过 Herdr 等待子 Agent 回报的最长时间；超时后先检查进展，再决定继续等待或重新派发。同一页的“ChatGPT Pro 自动审查”写入顶层 `chatgpt_review`，默认开；关闭后跳过本技能的自动 Pro 审查，本地 review 和测试照常，并与等待上限共用顶部保存、放弃、重新加载和冲突保护。侧栏收起时仅保留品牌图标，展开或移动抽屉显示品牌文字。

保存目标不存在时显示“尚未创建配置”，可直接点击“创建配置”保存默认模板，无需先修改字段。仅查看默认模板不算未保存编辑，也不会触发离开页面警告；创建成功后切回“保存配置”和同步状态，没有新编辑时保存按钮禁用。

保存失败保留输入并支持重试；409 冲突要求用户明确重新加载，重新加载和放弃修改均提示草稿损失。保存期间可继续编辑：提交成功只更新已保存快照和 revision，新输入仍保持 dirty。旧草稿校验响应不会覆盖当前结果。浏览器刷新和关闭有未保存提示。深色与浅色外观可切换，小屏导航使用控制台抽屉，排序与主要操作均有键盘入口。

保存可检测常规外部改动；外部编辑器在最终重读与原子替换之间写入仍有窄竞态，不提供跨进程原子 CAS。

```bash
bun run typecheck
bun run build
bun run test
```

构建产物输出 `dist/`，源码通过 Bun HTML bundler 提供。前端仅通过同源 API 获取 schema 和元数据，不运行时导入服务端 CLI 或 SQLite。Provider 禁用远程 webfont，资源不访问第三方。

`src/state.test.ts` 保护保存期间输入保留、revision 更新、旧草稿响应隔离与未知字段保留。后端测试位于 `tests/`。真实浏览器验收还应覆盖草稿校验、保存重载、冲突恢复、失败重试、排序、键盘、小屏、明暗主题及 console/network；类型检查和构建不能替代这些行为证据。所有写入验证使用临时配置与状态路径，保护真实持久数据。
